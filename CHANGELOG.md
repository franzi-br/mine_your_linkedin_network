# Changelog

## 1.0.0 (19 October 2026)

First public release, after one live run.

Added
1. Second pass prompt for what only you know, run on the shortlist after the first list is back. It was the biggest single quality lever in the first run.
2. Investors and board members as their own category and tab, with a first message that asks for a tip rather than a call.
3. Warm network tab for strong relationships in any function, kept separate from the scored list.
4. One contact per company rule ("contact first", "hold until the first replies").
5. Name checking against the export, after dictated names came out wrong.
6. Outreach tracker created in the first run, one row per message sent, with a fixed status list and a source column, so the reply rate can be calculated.
7. On request reporting of outreach stats with the sample size stated.
8. Outreach playbook with messaging rules and a follow up cadence.
9. "Before you send" checklist: CV versions, availability, notice period, salary floor.

Changed
1. Opening lines capped at about 60 words; apology first and "you may not remember me" handling.
2. Office policy added to the list of inferred fields to check.

## 0.1.0 (15 October 2026)

Private prompt kit: export steps, eight questions, the prompt, run steps, limits.
